# Учёба

Приложение для телефона, планшета и ПК: расписание пар, ДЗ и заметки, экспорт в Obsidian.
Работает без интернета и ставится на главный экран как обычное приложение (PWA).

**Адрес:** https://irequ1ern-oss.github.io/-/ (заработает после публикации, см. ниже).

## Что уже умеет

| Этап | Что готово |
| --- | --- |
| 1 | Экраны «Сегодня» и «Неделя», основное расписание, работа без интернета |
| 2 | Временное расписание на период и изменения на дату (в работе) |
| 3 | ДЗ, заметки, события |
| 4 | Экспорт для Obsidian, бэкап, импорт |
| 5 | Перенос в Obsidian командой `/ucheba-import` |
| 6 | Инструкция по установке на телефон и планшет |

### Как посмотреть другой день и час

Допиши к адресу `?now=` с датой и временем, например:
`https://irequ1ern-oss.github.io/-/?now=2026-10-12T10:17` — приложение покажет понедельник 10:17.
Сверху появится плашка «Тестовое время» с кнопкой «Сбросить».

## Как обновить основное расписание

Основное расписание лежит в файле [`data/schedule.json`](data/schedule.json).

**Проще всего:** напиши Claude Code что-то вроде «Со следующего семестра расписание такое: …» и приложи фото или текст.
Он поправит файл, тесты проверят его на ошибки, а после слияния изменений сайт обновится сам.

**Вручную:** у каждого предмета есть `id` (латиница, используется внутри), `short` (сокращение на карточке)
и `full` (полное название). Пары каждого дня — в `week.mon` … `week.fri` (`sat`, `sun` — если нужно):

```json
{ "start": "09:00", "end": "10:40", "subjectId": "mss", "room": "27", "note": "2-я подгруппа — каб. 25" }
```

Время пишется у каждой пары, потому что в разные дни звонки разные. `room` и `note` можно не указывать.
Если в файле будет ошибка (неизвестный предмет, пары накладываются, время не в формате ЧЧ:ММ),
тесты не пройдут, а приложение покажет красную плашку с описанием ошибки.

## Как запустить на своём компьютере (Windows 10)

Это нужно, только если захочется что-то посмотреть до публикации. Обычно хватает сайта.

1. Установи [Node.js](https://nodejs.org/) версии LTS (кнопка слева на сайте) и [Git](https://git-scm.com/download/win).
   Все настройки установщиков можно оставить по умолчанию.
2. Открой «Командную строку» (Пуск → набрать `cmd` → Enter) и выполни по очереди:
   ```
   cd %USERPROFILE%\Desktop
   git clone https://github.com/irequ1ern-oss/-.git ucheba
   cd ucheba
   npm ci
   npm run dev
   ```
3. В ответ появится адрес вида `http://localhost:5173/` — открой его в браузере.
   Остановить: `Ctrl + C` в окне командной строки.

Полезные команды:

| Команда | Что делает |
| --- | --- |
| `npm test` | Запускает тесты |
| `npm run typecheck` | Проверяет код на ошибки типов |
| `npm run build` | Собирает сайт в папку `dist` |

> Если вместо командной строки используешь PowerShell и видишь ошибку про «выполнение сценариев отключено»,
> пиши `npm.cmd` вместо `npm` или просто открой `cmd`.

## Как устроена публикация

- Каждый этап приходит как pull request (предложение изменений) из ветки `claude/…` в `main`.
  GitHub сам прогоняет проверку: типы, тесты, сборку.
- После нажатия **Merge** запускается публикация (`.github/workflows/deploy.yml`),
  и через 1–2 минуты сайт обновляется.
- Установленное приложение увидит новую версию при следующем открытии и покажет кнопку «Обновить».

## Устройство проекта

```
data/schedule.json        основное расписание
src/core/                 логика без интерфейса (покрыта тестами)
  time.ts                 время по Москве, даты
  schedule.ts             какое расписание действует на дату, следующая пара предмета
  today.ts                что показывать на экране «Сегодня»
  week.ts                 дни для экрана «Неделя»
  validate.ts             проверка data/schedule.json
src/screens/              экраны
src/components/           карточка пары, значки
src/data/schedule.ts      подключение основного расписания
public/icons/             иконки приложения
.github/workflows/        проверка и публикация
```

Стек: Vite, Preact, TypeScript, vite-plugin-pwa, Vitest.
Время всегда считается по Europe/Moscow, даже если на устройстве стоит другой часовой пояс.
