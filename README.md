# Учёба

Приложение для телефона, планшета и ПК: расписание пар, ДЗ и заметки, экспорт в Obsidian.
Работает без интернета и ставится на главный экран как обычное приложение (PWA).

**Адрес:** https://irequ1ern-oss.github.io/-/

**Превью дизайна** (все экраны и состояния на примерных данных): https://irequ1ern-oss.github.io/-/preview/

Внешний вид — в стиле iOS: большие заголовки, сгруппированные списки, стеклянные панели навигации,
вишнёвый акцент, свой цвет и иконка у каждого предмета. Темы: Авто, Светлая, Тёмная, AMOLED.
Правила дизайна — в [`docs/design.md`](docs/design.md).

### Как посмотреть другой день и час

Допиши к адресу `?now=` с датой и временем, например:
`https://irequ1ern-oss.github.io/-/?now=2026-10-12T10:17` — приложение покажет понедельник 10:17.
Часы пойдут дальше с этого момента. На экране «Сегодня» под датой появится строка «Тестовое время · Сбросить»:
нажми «Сбросить», чтобы вернуться к настоящему времени (или открой адрес без `?now=…`).

## Как обновить основное расписание

Основное расписание лежит в файле [`data/schedule.json`](data/schedule.json).

**Проще всего:** напиши Claude Code что-то вроде «Со следующего семестра расписание такое: …» и приложи фото или текст.
Он поправит файл, тесты проверят его на ошибки, а после слияния изменений сайт обновится сам.

**Вручную:** у каждого предмета есть `id` (латиница, используется внутри), `short` (сокращение в расписании),
`full` (полное название) и `icon` (иконка — название из [`src/ui/iconData.ts`](src/ui/iconData.ts);
с неизвестным названием будет иконка книги). Цвет подбирается сам, его можно поменять в «Настройки → Предметы».

```json
{ "id": "mss", "short": "МСС", "full": "Метрология, стандартизация и сертификация", "icon": "ruler" }
```

Пары каждого дня — в `week.mon` … `week.fri` (`sat`, `sun` — если нужно):

```json
{ "start": "09:00", "end": "10:40", "subjectId": "ig", "rooms": ["27", "25"] }
```

Время пишется у каждой пары, потому что в разные дни звонки разные. Кабинет — `"room": "27"`, а если у подгрупп
разные кабинеты — `"rooms": ["27", "25"]` (1-я и 2-я подгруппа; подгруппа выбирается в настройках приложения).
Кабинет можно не указывать. `note` — короткая пометка к паре, она видна в строке пары (например «принести штангенциркуль»).
Если в файле будет ошибка (неизвестный предмет, пары накладываются, время не в формате ЧЧ:ММ),
тесты не пройдут, а приложение при запуске покажет первую ошибку внизу экрана.

## Как запустить на своём компьютере (Windows 10)

Это нужно, только если захочется что-то посмотреть до публикации. Обычно хватает сайта.

1. Установи [Node.js](https://nodejs.org/) версии LTS (кнопка слева на сайте) и [Git](https://git-scm.com/download/win).
   Все настройки установщиков можно оставить по умолчанию.
2. Открой «Командную строку» (Пуск → набрать `cmd` → Enter) и выполни по очереди:
   ```
   cd %USERPROFILE%\Desktop
   git clone https://github.com/irequ1ern-oss/-.git ucheba
   cd ucheba
   npm ci
   npm run dev
   ```
3. В ответ появится адрес вида `http://localhost:5173/` — открой его в браузере.
   Остановить: `Ctrl + C` в окне командной строки.

Полезные команды:

| Команда | Что делает |
| --- | --- |
| `npm test` | Запускает тесты |
| `npm run typecheck` | Проверяет код на ошибки типов |
| `npm run build` | Собирает сайт в папку `dist` |

> Если вместо командной строки используешь PowerShell и видишь ошибку про «выполнение сценариев отключено»,
> пиши `npm.cmd` вместо `npm` или просто открой `cmd`.

## Как устроена публикация

- Каждый этап приходит как pull request (предложение изменений) из ветки `claude/…` в `main`.
  GitHub сам прогоняет проверку: типы, тесты, сборку.
- После нажатия **Merge** запускается публикация (`.github/workflows/deploy.yml`),
  и через 1–2 минуты сайт обновляется.
- Правки только README и `docs/` сайт не меняют и не публикуются.
- Установленное приложение проверяет обновления при запуске и когда его возвращают на экран (не чаще раза в полчаса,
  нужен интернет). Новая версия скачивается сама, внизу появляется «Вышла новая версия» с кнопкой «Обновить».
  Если кнопку не нажать — новая версия откроется при следующем запуске, то есть после того, как приложение
  полностью закрыли (на телефоне и планшете — смахнуть из списка недавних приложений, на ПК — закрыть окно).

## Устройство проекта

```
data/schedule.json        основное расписание
docs/design.md            дизайн-система: цвета, шрифты, компоненты, раскладки, жесты
src/core/                 логика без интерфейса (покрыта тестами)
  time.ts                 время по Москве, даты
  schedule.ts             какое расписание действует на дату, следующая пара предмета
  today.ts                фаза пары: прошла, идёт, впереди
  hero.ts                 главный блок «Сегодня»: идёт пара, перемена, до первой пары, выходной
  format.ts               подписи: даты, «через 37 мин», кабинеты
  colors.ts               автоподбор цветов предметов
  week.ts                 дни для экрана «Неделя»
  validate.ts             проверка data/schedule.json
src/ui/                   дизайн-система: токены (цвета, размеры), шрифт, иконки, компоненты
src/shell/                каркас: вкладки, боковое меню, навигация, часы
src/views/                экраны (today/, week/, homework/, notes/, settings/) и общие части:
                          строка пары, карточка предмета, шторка «+», колонка «Ближайшее»
src/state/                настройки (хранятся на устройстве)
src/main.tsx              запуск приложения
src/pwa.ts                работа без интернета и обновления
src/preview/, preview/    страница превью дизайна
src/data/schedule.ts      подключение основного расписания
public/icons/             иконки приложения
scripts/gen-icons.mjs     какие иконки Phosphor попадают в приложение
.github/workflows/        проверка и публикация
```

Стек: Vite, Preact, TypeScript, vite-plugin-pwa, Vitest.
Время всегда считается по Europe/Moscow, даже если на устройстве стоит другой часовой пояс.
