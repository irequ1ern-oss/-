# Эксплуатация Requiem

## Две сборки

`npm ci && npm run build` собирает публичный сайт GitHub Pages. `npm run build:account` в POSIX-окружении дополнительно собирает точку входа /account/ и её отдельный service worker. Сервер обслуживает обе части на одном HTTPS origin. Контейнер запускается одним экземпляром, хранит SQLite на постоянном диске /app/var, сбрасывает системные привилегии до приёма HTTP. Проверка работоспособности — GET /health. Обновление контейнера с тем же диском повторно запускает миграции.

## Первый вход

В настройках публичного приложения есть пункт «Аккаунт», если при сборке задан ACCOUNT_URL. На серверном хосте путь настраивается автоматически. Форма обычного входа находится по адресу /account/, первоначальная активация — /account/#activate.

Оператор может создать первого владельца в терминале сервера командой `python -m server.manage create-user Влад --owner --admin`. Команда запрашивает пароль без эха. Другой способ — установить криптографически случайный REQUIEM_ACTIVATION_CODE (минимум 32 символа), открыть страницу активации, ввести код и выбрать логин и пароль. Первая успешная активация закрывает этот путь для всей базы. После неё секрет можно убрать из переменных. Для отдельного администратора указывай только --admin. Роль администратора предоставляет доступ к публичным урокам и каталогу группы.

Для SQLite SQLite Online Backup API выполняет согласованную копию через `python -m server.manage backup /путь/к/новой-копии.sqlite3`. Восстанавливай на остановленном сервисе в пустую директорию постоянного диска после копирования текущей базы. Храни резервные копии и вложения в приватном хранилище. При компрометации копии отзови сессии. Импорт JSON в Workshop дополняет записи аккаунта одной транзакцией, конфликты останавливают весь импорт. SQLite-копия дополнительно включает вложения, учётные записи и аудит.

## Локальный запуск

Требуются Node 22 и Python 3.12. В корне установи зависимости, собери приватную версию и запусти один экземпляр uvicorn.

```sh
npm ci
npm run build:account
python -m venv .venv
. .venv/bin/activate
python -m pip install -r server/requirements.txt
export REQUIEM_ORIGIN=http://127.0.0.1:8080
export REQUIEM_DB=var/requiem.sqlite3
python -m server.manage create-user owner --owner --admin
uvicorn server.main:app --host 127.0.0.1 --port 8080
```

Открой http://127.0.0.1:8080/account/. В репозитории нет предустановленного пользователя. Для тестов используется отдельная временная база.

## Внешние сервисы

| Возможность | Настройка |
| --- | --- |
| Shay | На сервере задай SHAY_PROVIDER, SHAY_<PROVIDER>_KEY и SHAY_<PROVIDER>_MODELS. Имена моделей — через запятую из актуального каталога выбранного провайдера. В настройках Shay выбирается разрешённая модель. SHAY_MONTHLY_TOKENS ограничивает токены на аккаунт в календарном месяце. Финансовый предел задай также в кабинете провайдера. |
| Транспорт | Ручной ввод и импорт доступны без ключа. Персональный файл со снимками рейсов импортируется через «Дорога». Для внешнего источника укажи TRANSIT_FEED_URL с лицензированным HTTPS JSON-массивом рейсов. При замене рейса источнику нужно прислать cancelled=true для отменённого номера. При недоступности источника используются последние сохранённые записи на выбранную дату. |
| Web Push | Подготовь пару VAPID P-256. VAPID_PUBLIC_KEY и VAPID_PRIVATE_KEY принимают URL-safe base64 без padding, VAPID_CONTACT содержит HTTPS или mailto. В Oracle включи подписку на устройстве и создай правило. Для неизвестного push-сервиса оператор отдельно задаёт разрешённый домен в PUSH_ALLOWED_HOSTS. |
| Obsidian | OBSIDIAN_OWNER должен точно совпадать с логином владельца. Задай OBSIDIAN_REPO, OBSIDIAN_REF и опциональный OBSIDIAN_PREFIX. OBSIDIAN_TOKEN — fine-grained token только с Contents: Read для выбранного приватного репозитория. При импорте предлагается сохранить текст заметки. Markdown и URI доступны отдельно. |
| Поиск Shay | BRAVE_SEARCH_KEY включает поиск по внешним публичным страницам. Отрывки передаются модели как недоверенный текст. |
| Общий календарь | ACCOUNT_URL и PUBLIC_CALENDAR_URL при публикации Pages указывают на настроенный сервер. Гостевой клиент загружает только общий каталог и календарь, сохраняет последнюю прошедшую валидацию версию. |

## Источники и ограничения

Для одноразового снимка расписания нужна точная дата. При задержке меняются расчётные отправление и прибытие. При неизвестном последнем участке дороги интерфейс показывает время прибытия на станцию. Условия бесплатного сервиса Яндекс Расписаний ограничивают сценарии с закрытым доступом. Для приватного контура требуется согласованное право использования. Стандартный адаптер JSON не обращается к Яндексу.

- Документация и условия Яндекс Расписаний — https://yandex.ru/dev/rasp/doc/ru/reference/schedule-point-point и https://yandex.ru/legal/rasp_api/ru
- OpenAI, tool calling и цены — https://developers.openai.com/api/docs/guides/function-calling и https://developers.openai.com/api/docs/pricing
- Gemini, совместимый REST API и условия бесплатных моделей — https://ai.google.dev/gemini-api/docs/openai и https://ai.google.dev/gemini-api/docs/pricing
- OpenRouter, инструменты и лимиты — https://openrouter.ai/docs/guides/features/tool-calling и https://openrouter.ai/docs/api/reference/limits
- GitHub API дерева репозитория — https://docs.github.com/en/rest/git/trees
